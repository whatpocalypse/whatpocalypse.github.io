Privacy Policy

Effective date: 16 November 2026

This policy explains how the Whatpocalypse publisher application (“the app”) handles data, and how this website handles visits. The short version: the app is a private publishing tool for the Whatpocalypse YouTube channel, and it does not collect, store or share data from anyone else.

Who uses the app

The app is used only by the owner of the Whatpocalypse YouTube channel. It is not offered to the public, and no other person signs in to it or is granted access to it. Its only purpose is to:

  • upload videos to the channel owner’s own YouTube channel, and
  • post the first comment on those videos.

What data the app accesses

The app signs in to the channel owner’s own Google account with Google OAuth. Through the YouTube Data API it works only with the owner’s own channel: it sends the owner’s video files, titles, descriptions and comment text to YouTube, and it reads the owner’s own channel, videos and comments to confirm the right channel is signed in, that an upload has finished processing and that a comment is not posted twice.

The app does not collect, store or share any data from any other user. It does not read viewers’ personal information, it does not use analytics or advertising tools, and it does not sell data to anyone.

Google API scopes and why they are used

  • https://www.googleapis.com/auth/youtube.upload: to upload videos to the channel owner’s own YouTube channel, with their titles, descriptions and settings.
  • https://www.googleapis.com/auth/youtube.force-ssl: to post the first comment on the channel owner’s own videos, and to read the owner’s own channel, videos and comments for the checks described above.

The app requests no other scopes.

Where data is stored

OAuth tokens are stored only on the channel owner’s own computer. They are never uploaded to a server, a website or any third party. Data leaves that computer only when the app talks directly to Google’s own services to sign in, upload a video or post a comment.

Sharing

The app does not share, transfer or sell Google user data to anyone. Data obtained through Google APIs is not used for advertising, is not used to train any AI or machine learning model, and is not read by people other than the channel owner.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The app uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy.

How to revoke access

Access can be revoked at any time on the Google Account permissions page (https://myaccount.google.com/permissions). Revoking access stops the app from reaching the account. Deleting the token file on the channel owner’s computer removes the only stored copy of the tokens.

Retention and deletion

Tokens are kept on the channel owner’s computer until access is revoked or the token file is deleted. The app keeps no other copy of Google user data. Uploaded videos and posted comments stay on YouTube under the channel owner’s control and can be deleted there.

This website

This website uses no cookies, no analytics, no tracking and no scripts. It is hosted on GitHub Pages, which may log basic technical data such as IP addresses for security, as described in the GitHub General Privacy Statement. Links to YouTube, Instagram, TikTok and X lead to services with their own privacy policies.

Changes to this policy

If this policy changes, the new version is posted on this page with a new effective date.

Contact

Questions about this policy can be sent through the Whatpocalypse YouTube channel, for example in a comment on any video.
